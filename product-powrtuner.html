Completely re-engineered

The original PowrTuner earned a loyal following in the GM V6 community, but it was built around aging software and a third-party interface box that's no longer practical to depend on. The new PowrTuner is a fresh build: modern software paired with DHP's own Kepler interface, so the whole tool is something we control and can keep current.

What's different this time It's not just engine tuning anymore. PowrTuner has grown into a broader read/write and diagnostics tool for GM vehicles — useful for keeping an older car healthy, not only chasing more power.

What it's for

  • Reading and writing GM control programming, the way the original did — but on hardware we maintain.
  • Diagnostics and data logging to help track down faults and keep older vehicles running right.
  • Performance calibration work for the enthusiasts who knew PowrTuner the first time around.

Where it stands

This one is actively in development, and the exact feature set is still being finalized. If you'd like to help shape it — or you're a former PowrTuner user who wants first crack at the new version — we'd love to hear from you.
